 Visão GeralO ecossistema Open-Shield & Image-Lock foi concebido para devolver aos cidadãos ferramentas tecnológicas de proteção física e integridade digital, operando com total autonomia, privacidade e gratuidade universal.O projeto está dividido em duas aplicações independentes: Image-Lock (Módulo A): Garantia de imutabilidade, autenticidade e prova de origem de fotografia digital contra edições e manipulações por Inteligência Artificial. # Como Contribuir para o Open-Shield & Image-Lock
Agradecemos o seu interesse em contribuir para este projeto livre e comunitário!
## Regras de Ouro do Projecto1. **Privacidade Absoluta:** Nenhum dado de voz, imagem ou localização pode ser enviado para servidores externos. O processamento de IA/KWS deve ser 100% local (Edge Computing).2. **Gratuidade da Base:** A aplicação base e a comunicação via SMS para os 3 contactos pessoais do utilizador mantêm-se estritamente gratuitas sob a licença GPLv3.3. **Eficiência Energética:** O código para execução em segundo plano deve ser otimizado para consumo mínimo de bateria.
## Como Começar1. Faça um *Fork* deste repositório.2. Escolha um dos módulos para trabalhar:   - `módulo-a/image-lock`: Implementação de criptografia SHA-256 e ECDSA para imagens.   - `módulo-b/open-shield`: Motor de deteção de voz local (Offline KWS), RSSI Bluetooth e integração SMS/GPS.3. Submeta as suas alterações através de um *Pull Request* detalhado.

  Future<void> _pickAndProcessImage(ImageSource source) async {    try {      final XFile? pickedFile = await _picker.pickImage(source: source);      if (pickedFile == null) return;
      setState(() {        _isProcessing = true;        _selectedImage = File(pickedFile.path);      });
      final result = await ImageLockService.processImageFile(_selectedImage!);
      setState(() {        _lockResult = result;        _isProcessing = false;      });    } catch (e) {      setState(() => _isProcessing = false);      ScaffoldMessenger.of(context).showSnackBar(        SnackBar(content: Text('Erro ao processar imagem: $e')),      );    }  }
